# sf6-web-bridge releases

Download page for the SF Stats build of [sf6-web-bridge](https://github.com/type9/sf6-web-bridge), the REFramework plugin that lets sfstats.app talk to a running Street Fighter 6.

Grab the latest `sf6-web-bridge-sfstats-vX.Y.Z.zip` from [Releases](https://github.com/sfstatsapp/sf6-web-bridge-releases/releases/latest) and extract it into your `Street Fighter 6` folder (the one with `StreetFighter6.exe`). It adds `reframework/plugins/sf6-web-bridge.dll` and a `config.json` pinned to sfstats.app. REFramework (`dinput8.dll`) must already be installed.

The SF Stats desktop app downloads the same zip from here automatically. Each release ships a `SHA256SUMS.txt`.

This repository holds no source code. The plugin is MIT licensed; the SF Stats modifications live in a private repository.
